# CARA MENGGUNAKAN SCRIPT EVALUASI MODEL

## File: evaluate_model.py

Script ini digunakan untuk mengevaluasi performa model C4.5 dengan menampilkan:
- **Confusion Matrix** (dalam count dan percentage)
- **Accuracy** - Akurasi keseluruhan model
- **Precision** - Ketepatan prediksi Rusak
- **Recall** - Kemampuan mendeteksi SSD Rusak
- **F1-Score** - Harmonic mean dari Precision dan Recall
- **Classification Report** - Laporan lengkap per kelas

## Tips Meningkatkan Performa

1. **Tambah Data Training**
   - Saat ini: 48 data training
   - Rekomendasikan: >100 data untuk model yang lebih robust

2. **Balance Dataset**
   - Pastikan proporsi Normal:Rusak seimbang

3. **Feature Engineering**
   - Eksplorasi atribut SMART tambahan
   - Kombinasi fitur (feature interaction)

4. **Hyperparameter Tuning**
   - Adjust `min_samples` di C45Tree
   - Adjust `alpha` untuk Laplace Smoothing

## Troubleshooting

### Error: Model not found
```
Solusi: Jalankan python train_model.py terlebih dahulu
```

### Error: Import error
```
Solusi: pip install matplotlib seaborn scikit-learn
```

### Hasil berbeda setiap run
```
Penyebab: random_state di train_test_split
Solusi: Sudah di-set ke 42 (konsisten)
```
